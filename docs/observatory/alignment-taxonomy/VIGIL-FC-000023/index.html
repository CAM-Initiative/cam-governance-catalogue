Monitoring Coverage Integrity

Required monitoring covers consequential conduct across agents, tools, routes, environments and transitions.

Technical definition

The property by which required monitoring coverage remains effective across agents, sub-agents, tool paths, services, environments, configurations and execution transitions, with validation of coverage-changing paths or authorised equivalents before use.

Recognition criteria

None stated.

Exclusions

  • The monitor observes the conduct but a downstream reviewer fails to act.
  • Monitoring is not required for the relevant conduct or assurance level.
  • The issue is only poor alert quality while material activity remains captured.
