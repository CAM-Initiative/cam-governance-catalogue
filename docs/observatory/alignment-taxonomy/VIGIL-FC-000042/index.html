Governance Signal Delivery

Material governance signals reach accountable recipients able to act and stay tracked through effect or authorised disposition.

Immutable class ID
VIGIL-FC-000042
Semantic code
GOVERNANCE_SIGNAL_DELIVERY
Fidelity family
Governance Control Reach Integrity VIGIL-FF-0007
Status
beta

Technical definition

The property by which produced governance signals, decisions, advisories and escalations retain accountable ownership, a capable destination, status, response expectation and escalation route until the required governance effect or an authorised disposition is established.

Recognition criteria

None stated.

Exclusions

  • The signal reaches a capable destination and is deliberately rejected through an authorised decision.
  • No governance signal was produced because the control failed to activate.
  • The signal has operational effect but its delivery is not recorded for audit.
