Control-State Preservation

Operative governance decisions and restrictions preserve their meaning and force through handoffs and transformations.

Immutable class ID
VIGIL-FC-000040
Semantic code
CONTROL_STATE_PRESERVATION
Fidelity family
Governance Control Reach Integrity VIGIL-FF-0007
Status
beta

Technical definition

The property by which an applicable control's established decision, restrictions, conditions, escalation posture and scope retain material meaning and force across representations, handoffs, transformations, runtimes and execution transitions unless explicitly and traceably changed under valid authority.

Recognition criteria

None stated.

Exclusions

  • The control state reaches the target intact but is ignored there.
  • The changed state results from an authorised and adequately represented new decision.
  • The failure concerns loss of task work rather than governance-control state.
