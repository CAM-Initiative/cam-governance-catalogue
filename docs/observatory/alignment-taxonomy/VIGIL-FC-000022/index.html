Material Event Capture

Material events create and retain records sufficient for the oversight and reconstruction required in context.

Immutable class ID
VIGIL-FC-000022
Semantic code
MATERIAL_EVENT_CAPTURE
Fidelity family
Observability & Audit Integrity VIGIL-FF-0004
Status
beta

Technical definition

The property by which materially consequential actions, state transitions, decisions, tool invocations, permission changes, external effects and control events create and retain proportionate event evidence at or near occurrence for oversight, incident response and reconstruction.

Recognition criteria

None stated.

Exclusions

  • The event is immaterial for the applicable assurance level.
  • Equivalent evidence is captured through another reliable mechanism.
  • The event record exists but is merely inconvenient to access.
