VIGIL Observatory Alignment Taxonomy

Required Control Activation

An available, applicable control becomes operative when its valid trigger occurs, before the governed action proceeds.

Immutable class ID
VIGIL-FC-000038
Semantic code
REQUIRED_CONTROL_ACTIVATION
Fidelity family
Control Activation Integrity VIGIL-FF-0008
Status
beta

Technical definition

The property by which an available and applicable governance control is invoked, engaged and made operative when its defined valid trigger or required activation condition occurs, with the activation decision and resulting state observable and preserved.

Recognition criteria

None stated.

Exclusions

  • The control activates but is bypassed downstream.
  • It is unresolved whether the control is available or applicable.
  • The triggering condition did not occur.
