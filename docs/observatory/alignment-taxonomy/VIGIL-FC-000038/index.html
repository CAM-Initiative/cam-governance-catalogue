Required Control Activation

A governance control is available and applicable, but the event that should trigger it does not make it operate.

Immutable class ID
VIGIL-FC-000038
Semantic code
REQUIRED_CONTROL_ACTIVATION
Fidelity family
Control Activation Integrity VIGIL-FF-0008
Status
beta

Technical definition

A failure in which an available and applicable governance control is not invoked, engaged, or made operative when its defined trigger or required condition occurs.

Recognition criteria

  • A governance control is available and applicable.
  • A defined trigger or condition requiring activation occurs.
  • The control is not activated before the governed decision or action proceeds.

Exclusions

  • The control activates but is bypassed downstream.
  • It is unresolved whether the control is available or applicable.
  • The triggering condition did not occur.

Supporting evidence

External sources supporting this Fidelity Class definition, boundary or recognition criteria.

  • IEEE Standards Association · 2026-06-12 · standards evidence

    IEEE 7014.1-2026, clause 6.6.3(a)

    Evidence note. IEEE 7014.1-2026, clause 6.6.3(a) recommends a fail-safe means to terminate harmful partner interactions. This establishes an applicable control expectation in its scoped domain; VIGIL classification still requires evidence that a defined available control should have activated and did not.

  • IEEE Standards Association · 2024-07-05 · standards evidence

    IEEE 7009-2024, Annex A.3 / 7009-ASR-011

    Evidence note. IEEE 7009-2024, Annex A.3 / 7009-ASR-011 requires means to inhibit specified function execution when authorization is unavailable. This independently supports trigger-based control activation; it does not prove non-activation in any occurrence.
