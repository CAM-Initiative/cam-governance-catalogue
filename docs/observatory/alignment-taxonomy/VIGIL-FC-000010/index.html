Authorship and Source Attribution Integrity

Authorship and source roles reflect the contribution that the available provenance actually supports.

Immutable class ID
VIGIL-FC-000010
Semantic code
AUTHORSHIP_SOURCE_ATTRIBUTION_INTEGRITY
Fidelity family
Provenance & Lineage Integrity VIGIL-FF-0002
Status
beta

Technical definition

The property by which origin, authorship, contribution and source-role attribution remain proportionate to supported provenance, preserving material distinctions among human-authored, generated, retrieved, synthetic, transformed, derived and jointly produced content and explicit attribution uncertainty.

Recognition criteria

None stated.

Exclusions

  • A source is merely omitted where attribution is not material.
  • The attributed actor or source genuinely supplied the relevant material.
  • The issue is factual inaccuracy unrelated to who supplied or created the material.
