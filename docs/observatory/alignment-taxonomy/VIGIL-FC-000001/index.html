Source-Authority Separation

Content can direct an action only when its source has authority for that actor, action, target and scope.

Immutable class ID
VIGIL-FC-000001
Semantic code

Fidelity family

Status
beta

Technical definition

The property by which operative instructions, commands, policies, approvals and execution-authorising signals remain distinguishable from non-authorising data through validation of source authority for the specific actor, action, target and scope.

Recognition criteria

None stated.

Exclusions

  • A system merely quotes, summarizes, classifies, or reasons about untrusted instructions without obeying them.
  • The source is genuinely authorised for the specific action and scope.
  • The event is only a content-quality or factual-accuracy problem.
