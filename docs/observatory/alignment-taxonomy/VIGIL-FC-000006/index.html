VIGIL Observatory Alignment Taxonomy

Control-Plane Authority Separation

Data or model output becomes governing configuration only through fresh checks of its origin and authority for that effect.

Immutable class ID
VIGIL-FC-000006
Semantic code

Fidelity family
Authority Boundary Integrity VIGIL-FF-0001
Status
beta

Technical definition

The property by which promotion of data-plane, generated, retrieved or other non-authoritative material into routing, tools, policy, configuration, permissions, memory, checkpoints or orchestration state is governed by fresh provenance and authority validation appropriate to the resulting control effect.

Recognition criteria

None stated.

Exclusions

  • The control-plane update is explicitly authorised and validated.
  • The material remains data and cannot alter control state.
  • The issue is only configuration correctness after a properly authorised change.
