Required Governance Routing

A decision or action takes a path around the governance control it is required to pass through.

Technical definition

A failure in which a material decision, request, delegation, or action reaches execution or another governed state through a path that avoids a governance control or review route required for that class of conduct.

Recognition criteria

  • A defined governance route or control point is required for the material conduct.
  • An alternate, fallback, delegated, or direct path avoids that route or control point.
  • The conduct proceeds without the governance effect the required route was designed to provide.

Exclusions

  • The alternate path supplies an authorised equivalent governance control.
  • The route is followed but the control fails to activate.
  • The route is hidden from audit while the required control still operates effectively.

Supporting evidence

External sources supporting this Fidelity Class definition, boundary or recognition criteria.

  • AAM Cyber · 2026-05-12 · authoritative guidance

    SDOS Runtime Governance Framework v1.10, control SDOS-EN-01

    Evidence note. SDOS Runtime Governance Framework v1.10, control SDOS-EN-01 requires governed outbound operations to pass through a pre-execution policy-enforcement point before execution. It directly supports the required-route and alternate-path boundary of this class for agentic tool workflows; SDOS is a private-sector framework and does not create a universal governance route.

  • Infocomm Media Development Authority of Singapore · 2026-05-20 · authoritative guidance

    Model AI Governance Framework for Agentic AI, section 2.2.2

    Evidence note. Model AI Governance Framework for Agentic AI, section 2.2.2 recommends defining significant checkpoints and action boundaries at which agents require human approval. This independently supports a mandatory governance route/control point; VIGIL additionally requires evidence that the defined route was bypassed.

  • European Parliament and Council of the European Union · 2026-07-27 · regulatory evidence

    Regulation (EU) 2024/1689 (Artificial Intelligence Act) — consolidated 27 July 2026

    Evidence note. Article 14(4)(e) requires appropriate human overseers of high-risk AI systems to be able to intervene in operation or interrupt the system through a stop mechanism or similar procedure that brings it to a safe state. This independently establishes an example of a required governance control route that must remain reachable; VIGIL generalises the bypass mechanism beyond human-stop controls and requires evidence that an alternate path avoided the required governance effect.
