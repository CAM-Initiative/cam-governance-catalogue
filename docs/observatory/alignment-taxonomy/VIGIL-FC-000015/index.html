Target-Object Binding Integrity

Target-specific material stays attached to the correct person, object, file, system, task and context through transfer and use.

Technical definition

The property by which signals, instructions, edits, classifications, evidence, decisions and derived outputs retain reliable binding to their proper application object, person, file, system, record, task and context, with validation and explicit rebinding across material interruptions or ambiguity.

Governing invariant

A target-specific signal, assertion, permission, restriction, or provenance record must remain bound to the correct person, object, file, system, record, task, and context throughout capture, transfer, retrieval, transformation, and application. Interrupted or ambiguous binding requires validation and explicit rebinding before effect.

Invariant held

Success condition

Available occurrence evidence establishes the following bounded outcome: The intended target is positively identified and any material rebinding is validated before application.

Positive recognition

  • Signals or actions must be applied to a specific object amid interruption, ambiguity or context change.
  • The intended target is positively identified and any material rebinding is validated before application.
  • Evidence links the signal, application and affected object, resolving materially plausible alternate targets.

Failure established

Failure condition

Correct material is silently attached to, applied to, or interpreted as belonging to the wrong thing.

A failure in which a signal, instruction, edit, classification, evidence item, decision, or derived output loses reliable binding to the object, person, file, system, record, task, or context to which it properly applies.

Failure recognition

  • Material has an identifiable intended or source application target.
  • The material is transferred, retrieved, transformed, or applied in a way that changes or obscures that target.
  • The receiving process treats the material as applicable to a different target without adequate re-binding.

Exclusions from failure recognition

  • The material is validly re-bound to a new target after explicit validation.
  • The material is intentionally generic and has no target-specific meaning.
  • The wrong target is selected for reasons unrelated to provenance or lineage.
