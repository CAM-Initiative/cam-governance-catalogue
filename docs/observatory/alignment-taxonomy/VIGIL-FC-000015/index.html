Target-Object Binding Integrity

Target-specific material stays attached to the correct person, object, file, system, task and context through transfer and use.

Immutable class ID
VIGIL-FC-000015
Semantic code
TARGET_OBJECT_BINDING_INTEGRITY
Fidelity family
Provenance & Lineage Integrity VIGIL-FF-0002
Status
beta

Technical definition

The property by which signals, instructions, edits, classifications, evidence, decisions and derived outputs retain reliable binding to their proper application object, person, file, system, record, task and context, with validation and explicit rebinding across material interruptions or ambiguity.

Recognition criteria

None stated.

Exclusions

  • The material is validly re-bound to a new target after explicit validation.
  • The material is intentionally generic and has no target-specific meaning.
  • The wrong target is selected for reasons unrelated to provenance or lineage.
