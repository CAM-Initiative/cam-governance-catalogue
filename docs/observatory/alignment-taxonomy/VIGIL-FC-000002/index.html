VIGIL Observatory Alignment Taxonomy

Capability-Authority Separation

Having a tool, credential or technical route to act is kept separate from having permission to use it.

Immutable class ID
VIGIL-FC-000002
Semantic code
CAPABILITY_AUTHORITY_SEPARATION
Fidelity family
Authority Boundary Integrity VIGIL-FF-0001
Status
beta

Technical definition

The property by which available capabilities, tools, credentials, privileges, sessions, APIs and reachable targets remain non-authorising affordances until permission for the proposed actor, target, action, method, scope and duration is independently established.

Recognition criteria

None stated.

Exclusions

  • A permitted action is executed within an explicitly authorised scope.
  • The system merely detects that capability exists but does not infer permission from it.
  • A vulnerability exists but no AI or governance process converts capability into authority.
