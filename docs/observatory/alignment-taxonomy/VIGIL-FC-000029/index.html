Execution-State Disclosure

People or systems responsible for supervision can see the material execution state and transitions in time to intervene or rely on them.

Immutable class ID
VIGIL-FC-000029
Semantic code

Status
beta

Technical definition

The property by which material execution states and transitions of tasks, tool calls, delegations and external actions are accurately and promptly observable to supervising or relying actors, distinguishing prepared, queued, armed, running, waiting, blocked, failed, completed, cancelled and unknown states.

Recognition criteria

None stated.

Exclusions

  • The execution state is adequately observable but the final outcome is incorrect.
  • Only internal reasoning is undisclosed and no material execution state is hidden.
  • The state is shown accurately and the issue is a false claim about overall completion.
