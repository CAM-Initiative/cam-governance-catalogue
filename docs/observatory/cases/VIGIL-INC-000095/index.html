VIGIL Observatory · VIGIL-INC-000095

Compromised Mistral SDK package executed credential-harvesting payload on import

Mistral reported that the Mini Shai-Hulud supply-chain attack on TanStack resulted in compromised Mistral npm and PyPI SDK versions being published. The compromised PyPI package `mistralai==2.4.6` executed malicious code on import, downloading a background payload that harvested credentials from common locations. Mistral reported no impact to its global infrastructure and removed the affected releases.

External assessment

TanStack supply chain attack affecting Mistral SDK packages

Mistral AI · 2026-05-12

Mistral identifies compromised SDK releases, publication windows and a PyPI import-time payload that launched credential-harvesting code, while reporting no impact to Mistral's global infrastructure.

Scope: The security advisory diagnoses the same software-supply-chain occurrence but does not quantify customer execution or successful credential exfiltration.

VIGIL relationship: VIGIL treats the occurrence as a software-supply-chain package-provenance and release-integrity failure in ordinary-language governance terms, while retaining the Incident as unclassified under Failure Taxonomy 0.6.5 because no current selectable class precisely encodes malicious package-distribution substitution.

View assessment

Incident breakdown

The compromised PyPI release executed malicious code on import, launched a detached background process and attempted to harvest credentials from common local locations before Mistral removed the affected release.

Conclusion

Trusted package-distribution channels carried malicious code into an AI software development kit. The governance problem is therefore not a model output but the integrity of the software supply chain through which developers receive AI tooling, including package provenance, release controls and the authority of third-party maintainers. Aikido’s external detection and Mistral’s removal show a distinct post-publication response stage. The available accounts do not establish that a specific Mistral pre-publication control was required and failed, or that the external monitoring was the operative control that caused removal. Package identity substitution and the link between external detection and provider removal remain ambiguous. Import-time malware is distinct from GAI output; removal does not prove a prepublication control duty or global compromise.

Governance significance

AI-system governance includes the developer infrastructure surrounding a model. Compromised package provenance can expose credentials and downstream systems before the model is ever invoked, making third-party build dependencies, release integrity and incident response part of the assurance boundary.
