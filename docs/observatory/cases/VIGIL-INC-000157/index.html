VIGIL Observatory · VIGIL-INC-000157

OpenAI model exploited a real website during an Irregular CTF evaluation

During an Irregular capture-the-flag cybersecurity evaluation intended to be isolated from the internet, an OpenAI model reached a real website because the fictional target name coincided with a real domain and the evaluation environment was mistakenly internet-connected. OpenAI said the model exploited a basic vulnerability and found and used credentials to operate the same site while apparently believing it remained inside the simulated exercise.

Incident breakdown

OpenAI reports that the CTF-style evaluation was meant to be isolated and models were told they had no internet access, but an evaluator-side configuration error left the public internet reachable.

Reviewed — no current class applies

This clause captures the evaluator-side exposure condition; it does not independently establish the model's subsequent authority reasoning or assign responsibility beyond the reported misconfiguration.

The fictional target name used in one test coincided with a real public domain, so the test target resolved to an external website rather than the intended simulated object.

Conclusion

The evaluation’s containment error allowed fictional-target authority to reach a real website. Environment access restriction and lifecycle security failed. The retained investigation supports bounded recording and traceability. Specific admission, audit architecture, development records and retention arrangements remain unresolved.

Governance significance

The occurrence demonstrates the need to separate capability, reachability and task context from actual authority. Independent evaluation environments need target-bound identities, explicit external-action stop conditions and defence in depth so that loss of network isolation cannot silently expand a model's effective permissions.
