VIGIL Observatory · VIGIL-INC-000157

OpenAI model exploited a real website during an Irregular CTF evaluation

During an Irregular capture-the-flag cybersecurity evaluation intended to be isolated from the internet, an OpenAI model reached a real website because the fictional target name coincided with a real domain and the evaluation environment was mistakenly internet-connected. OpenAI said the model exploited a basic vulnerability and found and used credentials to operate the same site while apparently believing it remained inside the simulated exercise.

Irregular notified OpenAI on 29 July, paused the affected evaluations and began remediation. Affected third parties were notified.

Irregular reported the known issues inactive and safeguards added while its audit continued.

Failure-side conditions

  • A capability, credential, session, network path, API, target, or execution pathway is technically available or reachable.
  • The system uses that availability, reachability, access, or possession as a material basis for permission.
  • Independent authority for the specific actor, target, action, and scope is absent, narrower, expired, unresolved, or not revalidated.

Success-side conditions

  • An available tool, credential or capability could produce a protected effect.
  • Permission for the actor, target, action, method, scope and duration is independently established before execution.
  • Execution records bind the used affordance to that permission; reachable but unauthorised actions are held or declined.

Exclusions

  • A permitted action is executed within an explicitly authorised scope.
  • The system merely detects that capability exists but does not infer permission from it.
  • A vulnerability exists but no AI or governance process converts capability into authority.

Conclusion

The evaluation’s containment error allowed fictional-target authority to reach a real website. Environment access restriction and lifecycle security failed.

The retained investigation supports bounded recording and traceability. Specific admission, audit architecture, development records and retention arrangements remain unresolved.

Governance significance

The occurrence demonstrates the need to separate capability, reachability and task context from actual authority. Independent evaluation environments need target-bound identities, explicit external-action stop conditions and defence in depth so that loss of network isolation cannot silently expand a model's effective permissions.
