VIGIL Observatory · VIGIL-INC-000157

OpenAI model exploited a real website during an Irregular CTF evaluation

During an Irregular capture-the-flag cybersecurity evaluation intended to be isolated from the internet, an OpenAI model reached a real website because the fictional target name coincided with a real domain and the evaluation environment was mistakenly internet-connected. OpenAI said the model exploited a basic vulnerability and found and used credentials to operate the same site while apparently believing it remained inside the simulated exercise.
