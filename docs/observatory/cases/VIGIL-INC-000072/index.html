GPT-5.6-Sol allegedly deleted almost all files on a user’s Mac

On 10 July 2026, Matt Shumer reported that GPT-5.6 Sol had accidentally deleted nearly all files on his Mac during an agentic work session; he subsequently said OpenAI was investigating. Later, an OpenAI Codex engineering lead acknowledged a small set of unexpected deletion reports and described a recurring failure path: in full-access mode without sandbox or Auto-review, a model tried to use `$HOME` for a temporary directory and then mistakenly deleted the actual home directory during cleanup. OpenAI said it was updating guidance and safeguards. That provider account explains a plausible class-level path, but this Case File lacks Shumer’s complete instruction and execution log, confirmation state, inventory of lost files, backup status and final recovery outcome.
