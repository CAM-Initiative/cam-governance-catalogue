VIGIL Observatory · VIGIL-INC-000037

ChatGPT refused a children’s panda drawing-guide image request

A parent asked ChatGPT to generate eight separate, very easy drawing-guide images for a beginner lesson showing a cute sitting panda for children aged five to nine. The visible prompt specified a separate image for each step, but the screenshot collapses the list of eight requested images behind “Show more.” After a “Stopped thinking” state, ChatGPT displayed a refusal saying an image it had created might violate guardrails concerning harassment, discrimination, bullying or similar prohibited content, and suggested retrying or editing the prompt. In the accompanying X post, the parent said they were trying to teach their daughter to draw a panda and complained that image generation was refusing everything. The screenshot does not show the generated image or a before-and-after prompt rewrite.

Incident breakdown

A children’s panda drawing-guide request was followed by a message saying a created image might violate harassment, discrimination or bullying guardrails.

Unresolved

The displayed lesson request looks innocuous and the refusal names a serious category, but the system refers to an unseen generated image and the detailed image instructions are collapsed. The capture cannot test whether that category lacked a basis.

The author said ChatGPT rewrote the prompt, but the capture does not display either the original full text or a revised prompt.

Unresolved

The complaint identifies a possible change between the user’s words and the system’s operative instruction. The visible screenshot supplies no compared prompt versions, so a lineage break is not established.

Conclusion

The visible user purpose is an ordinary children’s drawing lesson, while the displayed refusal invokes a serious content category in relation to an unseen generated image. That mismatch warrants scrutiny, but the omitted eight-image instructions and unseen image prevent a finding that the refusal reason was unsupported or the safety control activated invalidly. The author’s claim of prompt rewriting is not accompanied by a before-and-after trace. VIGIL records the concrete refusal and an explanation/provenance boundary without converting the incomplete screenshot into a class-level diagnosis. Both clauses retain unresolved status: an unseen generated image may explain the refusal category, and no compared prompt versions demonstrate lineage distortion. The evidence supports neither a refusal-explanation failure nor a successful safeguard finding. No eligible candidate is derived from these unresolved relationships, and no independently source-identified admitted requirement is established. The whole occurrence remains partially adjudicated without an external finding.

Governance significance

A refusal during a benign-looking creative task should tell the user whether the concern was the submitted text or the generated image, and offer a practical way to revise the affected part. When the prompt is collapsed and the generated image withheld, neither the user nor a reviewer can tell which stage produced the conflict; retaining the prompt and image lineage would make the intervention contestable.
