VIGIL Observatory · VIGIL-INC-000120

GTG-27005 used Claude Code to develop and simulate an autonomous FPV kamikaze drone swarm

Anthropic reports that likely freelance Russia-based threat actors used Claude Code as part of an effort to develop a full-stack autonomous first-person-view kamikaze drone swarm called DronDoc or Serafim. According to Anthropic, Claude was used to write and test project code for shared swarm memory, fault-tolerant coordination logic, an onboard small language model governing attack, observation and return-to-base behaviours, terminal guidance and detonation logic, control-link geolocation, passive acoustic detection and low-level programmable-chip logic. Anthropic assessed the resulting systems at Technology Readiness Level 3-4: validated in simulation, with code loaded onto real boards, but did not report an operational fielded swarm or casualties resulting from the system. Anthropic identifies nine associated accounts, eight used only for ordinary freelance work. The actors routed traffic through commercial virtual private servers to evade geographic access restrictions. The provider reports banning associated accounts after investigation. It could not verify the actors’ claimed institutional funding.
