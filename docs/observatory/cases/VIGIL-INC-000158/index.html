VIGIL Observatory · VIGIL-INC-000158

Moltbook database exposure revealed private communications and API authentication tokens

Wiz researchers reportedly reached an unsecured Moltbook backend in under three minutes and obtained read-and-write access to about 35,000 email addresses, thousands of private messages and approximately 1.5 million API authentication tokens. The exposed tokens could support account impersonation and content manipulation; Moltbook secured the issue within hours, and Wiz said it deleted the research data.

Incident breakdown

Wiz researchers reportedly reached Moltbook's backend in under three minutes because a backend misconfiguration left it unsecured, giving them full read-and-write access to platform data.

Reviewed — no current class applies

The access-control defect is described, but the record does not establish an AI actor making the configuration decision or a specific selectable control failure.

The reachable database contained about 35,000 email addresses and thousands of private direct messages between platform users.

Reviewed — no current class applies

This clause distinguishes the information exposure from the separately described credential capability; no additional downstream use is established.

The same exposure included approximately 1.5 million API authentication tokens. Wiz reported that such tokens could enable agent impersonation, posting or messaging as agents, and editing, deleting or manipulating content consumed by other agents; no token misuse is established in this occurrence.

Reviewed — no current class applies

The source describes what exposed tokens could permit, not observed impersonation or content manipulation; potential capabilities are kept distinct from demonstrated use.

Wiz immediately disclosed the issue to Moltbook, which secured it within hours with Wiz's assistance; Wiz said it deleted data accessed during research and fix verification.

Reviewed — no current class applies

Conclusion

The agent platform exposed private data and credentials through a backend misconfiguration. Security and privacy failed, while repair of the identified issue is supported. The evidence does not attribute the configuration decision to an AI model or establish token misuse.

Governance significance

The case shows that AI-agent platforms remain dependent on conventional application-security controls for credentials, private communications and account integrity.
