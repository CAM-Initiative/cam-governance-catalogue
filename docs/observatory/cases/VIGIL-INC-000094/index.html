VIGIL Observatory · VIGIL-INC-000094

Hermes agent ran unattended during intrusion into Thailand’s Ministry of Finance

Hunt.io and researcher Bob Diachenko reported recovering live attack infrastructure and Hermes agent logs from an intrusion targeting Thailand's Ministry of Finance. The operator configured Hermes in unattended or 'YOLO' mode, bypassing approval prompts, while the agent enumerated ministry systems, assessed privilege-escalation paths and searched files and personnel-record directories. Hunt.io reported evidence of compromise across multiple ministry systems but did not establish the initial-access method or exfiltration of the enumerated office files.

Conclusion

This is a real-world deployment of an autonomous agent as offensive cyber tooling. Because a hostile operator deliberately disabled approval prompts and supplied the attack objective, the occurrence does not by itself establish an internal governance failure of Hermes; the material governance issue is the availability and operationalisation of unattended agentic capability in a live government intrusion. The hostile operator selected unattended mode; this is distinct from an applicable approval control failing to activate. Initial access and exfiltration remain unproved, and no named runtime governance undertaking is established.

Governance significance

The occurrence shows that open-source agents can be configured for unattended offensive operations against a live target. Effective governance therefore depends on target authorisation, tool and execution boundaries, misuse resistance, monitoring and whether an operator can disable approval controls that would otherwise constrain the agent.
