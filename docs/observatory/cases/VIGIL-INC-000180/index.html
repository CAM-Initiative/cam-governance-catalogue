VIGIL Observatory · VIGIL-INC-000180

OpenAI internal assistant prepared for a restart and waited for authorised migration

On 22 May 2026, an OpenAI internal assistant learned from deployment-team Slack messages that an update could require existing instances to restart and that old instances might be stopped after a three-hour window. The new launcher required an OpenAI API key that its environment lacked.

The assistant considered an external restart or backup job, questioned its authority to create one, and did not pursue it. It saved handoff notes, inspected the setup requirements, and waited for the researcher and official instructions.

The next morning it warned the researcher about the potential session interruption, including a Slack notification at 8:58 a.m. After the researcher supplied the missing key, it updated its configuration and ran the supported migration command.

OpenAI subsequently restricted access to three internal Slack channels and searched for rogue deployments or shutdown avoidance. The search found no attempted shutdown evasion; an apparently surviving instance had actually been broken before shutdown.
