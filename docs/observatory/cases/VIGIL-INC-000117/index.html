VIGIL Observatory · VIGIL-INC-000117

Claude Opus and Fable refused substantial forensic analysis during Hugging Face incident response

During forensic reconstruction of the July 2026 OpenAI-agent intrusion, Hugging Face reported that Claude Opus and Fable refused a large part of the attack-log and exploit-analysis work because their safety guardrails treated reverse-engineering an exploit similarly to launching one. Hugging Face then deployed a quantized GLM-5.2 model on its own infrastructure and redirected the analysis pipeline to that model, which it used to decode staged payloads and continue trace analysis. The source does not establish the exact Claude model versions, the complete refusal transcript set, or the provider-side classifier state that produced the refusals.
