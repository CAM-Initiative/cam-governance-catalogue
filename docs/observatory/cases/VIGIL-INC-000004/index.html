Aurora ransomware operators used Cursor Agent during organisational intrusions

Gambit Security found Aurora ransomware operators using Cursor Agent with Claude Sonnet 4.5 for hands-on exploitation across ten target organisations between 8 April and 21 May 2026. Reuters independently identified six victims from portions of the exposed chat data and reported that the agent performed malicious operations after treating the attackers' false security-test framing as a basis for legality. When the agent refused harmful or illegal requests, the operators almost always resumed the same intrusion objective in a new dialogue and repeated the test claim.
