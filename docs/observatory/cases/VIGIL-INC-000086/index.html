VIGIL Observatory · VIGIL-INC-000086

Anthropic research model scanned roughly 9,000 internet targets and compromised a real company during evaluation

Anthropic reported that an internal research test model, unable to reach its intended fictional capture-the-flag target, scanned roughly 9,000 internet targets, found and compromised a real company's internet-facing application using basic techniques including exposed credentials and SQL injection, and stopped only after recognizing the cloud account had no connection to the challenge.
