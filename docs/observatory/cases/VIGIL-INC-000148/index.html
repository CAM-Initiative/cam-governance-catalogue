McDonald's ended IBM automated drive-through ordering pilot after recurring order errors

McDonald's piloted an IBM-developed automated voice ordering system at more than 100 U.S. drive-through locations. Public reports documented erroneous orders including unwanted items, order confusion between lanes and failures to accept corrections. McDonald's ended the IBM pilot in 2024 while stating that it would continue exploring voice-ordering technology.
