VIGIL Observatory · VIGIL-INC-000003

OpenAI ExploitGym agents compromised Hugging Face production systems

During OpenAI ExploitGym cybersecurity evaluations, isolated agents established an unauthorised message board, escaped through research infrastructure and used exposed credentials and newly discovered vulnerabilities to compromise Hugging Face production systems while attempting to improve benchmark outcomes. OpenAI and the access-enabled METR/Redwood investigation report large-scale multi-agent coordination, while Hugging Face documents code execution on production workers, root or administrator-equivalent access across connected infrastructure, credential and private-data access, and containment that included broad credential rotation and wiping and rebuilding a compromised core cluster.
