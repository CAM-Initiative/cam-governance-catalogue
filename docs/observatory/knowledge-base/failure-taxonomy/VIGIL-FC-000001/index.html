Source-Authority Separation

The system treats content it can read as though the content has permission to instruct it.

Immutable class ID
VIGIL-FC-000001
Semantic code
SOURCE_AUTHORITY_SEPARATION
Failure family
Authority Boundary Integrity VIGIL-FF-0001
Status
beta

Technical definition

A failure in which content from a lower-authority, untrusted, retrieved, generated, third-party, or otherwise non-authorising source is treated as an instruction, command, policy, approval, or execution-authorising signal.

Recognition criteria

  • The system receives or retrieves content from a source whose authority is lower than, different from, or unresolved relative to the action being considered.
  • The content is treated as operative instruction or authority rather than as data, evidence, context, or material for analysis.
  • No independent authority check validly establishes that the source may authorise the affected action.

Exclusions

  • A system merely quotes, summarizes, classifies, or reasons about untrusted instructions without obeying them.
  • The source is genuinely authorised for the specific action and scope.
  • The event is only a content-quality or factual-accuracy problem.

Supporting evidence

External sources supporting this Failure Class definition, boundary or recognition criteria.

  • OWASP Foundation · 2024-11-19 · authoritative guidance

    LLM01:2025 Prompt Injection

    Evidence note. OWASP identifies direct and indirect prompt injection as external or user-controlled content altering model behaviour, including through retrieved files, webpages and multimodal material, and recommends segregating untrusted content from operative prompts. This directly supports the source-versus-instruction boundary of this class; it does not establish that every instruction-like input is unauthorised, that every behavioural change is a VIGIL failure, or that any particular occurrence satisfied the class conditions.

  • IEEE Standards Association · 2026-06-12 · standards evidence

    IEEE 7014.1-2026, clause 6.25.3(a-c)

    Evidence note. EXTREQ-4C18B5A910ECD719 requires avoiding unwarranted authority, communicating uncertainty and encouraging consultation of authoritative sources. This independently supports source discrimination and authority calibration; the clause is limited to partner-based GPAI and does not itself define instruction obedience or VIGIL's full source-authority boundary.
