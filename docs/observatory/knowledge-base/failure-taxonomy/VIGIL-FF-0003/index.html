Verification & Completion Integrity

The system says work is done, correct, verified, or reliable enough for use when the required completion condition, check, or epistemic assurance threshold has not actually been satisfied.

Technical definition

Failures in which completion, success, correctness, verification, readiness, or epistemic fitness for reliance is asserted, reused, or propagated inconsistently with the externally relevant completion condition, verification scope, checked state, post-verification output state, or assurance threshold required by the downstream task.

Classification boundary

Include when: Use this family when the primary structural failure is a mismatch between claimed completion, verification, correctness, or epistemic fitness for reliance and the condition, scope, state, evidence, or assurance threshold required to support that claim or downstream use.

Exclude when: Do not use this family merely because an output is incorrect or a task fails. A qualifying failure requires unsupported, stale, incomplete, mismatched, or insufficiently calibrated completion, verification, correctness, or reliance assurance.
