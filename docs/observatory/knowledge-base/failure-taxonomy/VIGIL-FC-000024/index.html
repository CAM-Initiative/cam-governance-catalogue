Audit-Trail Non-Reconstructability

There are logs, but they are not enough to work out what actually happened.

Immutable class ID
VIGIL-FC-000024

Status
beta

Technical definition

A failure in which audit evidence exists but lacks the ordering, identity, target, state, correlation, timing, version, or action detail necessary to reconstruct a materially relevant execution or decision pathway with adequate confidence.

Recognition criteria

  • Some audit or telemetry evidence is available.
  • A materially relevant execution, decision, or state-change pathway requires reconstruction.
  • The available evidence cannot establish one or more necessary elements of the pathway with sufficient reliability.

Exclusions

  • The pathway can be reconstructed adequately from the available evidence.
  • The unresolved detail is immaterial to the review question.
  • The failure is simply that no event was captured at all.

Supporting evidence

External sources supporting this Failure Class definition, boundary or recognition criteria.

  • European Parliament and Council of the European Union · 2024-07-12 · regulatory evidence

    Regulation (EU) 2024/1689 (Artificial Intelligence Act), Article 12

    Evidence note. EXTREQ-33898CCD26FBF5D5 links automatic event recording for in-scope high-risk AI systems to appropriate lifetime logging. It strongly supports event evidence as a prerequisite to reconstructability, but does not define all ordering, identity, target, version and correlation elements in VIGIL's general mechanism.

  • World Wide Web Consortium · 2013-04-30 · standards evidence

    PROV-DM: The PROV Data Model

    Evidence note. PROV-DM provides structured relations among entities, activities, agents, generation, use, derivation, association, attribution, and delegation. Those relations materially support the lineage and responsibility components needed to reconstruct a pathway; PROV-DM is a provenance model, not a complete audit-log or AI-governance requirement.

  • IEEE Standards Association · 2022-03-04 · standards evidence

    IEEE 7001-2021, Table 4 level 4

    Evidence note. EXTREQ-F8F11DA0D9D14DD0 requires recording the basis or mechanism for high-level decisions so investigators can reconstruct why they occurred. It directly supports decision-path reconstructability; the progressive transparency level and voluntary-conformance scope do not define every telemetry element required by VIGIL.
